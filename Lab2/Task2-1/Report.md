### 3. 操作說明與成果
1. **電路連接**：延續 Basic Task 2-1 的 L293D 直流馬達驅動電路，另外加入可變電阻（Potentiometer）。將可變電阻兩側接腳分別連接 Arduino 的 5V 與 GND，中間訊號腳連接至 A0，用來讀取旋鈕角度。L293D 的 1A、2A 接至 Arduino 數位輸出腳位以控制馬達旋轉方向，而 1,2EN 接至支援 PWM 的腳位，以控制馬達轉速。
2. **讀取可變電阻**：在程式中使用 `analogRead(A0)` 讀取可變電阻訊號，其輸入值約為 0～1023。當旋轉旋鈕時，可透過 Serial Monitor 觀察數值的變化，並以此數值判斷馬達應旋轉的方向及速度。
3. **方向控制**：利用 L293D 的兩個輸入端控制馬達方向。當 `1A = HIGH`、`2A = LOW` 時，馬達向其中一個方向旋轉；將兩者狀態交換為 `1A = LOW`、`2A = HIGH` 時，馬達則向相反方向旋轉。
4. **速度控制**：利用 Arduino 的 `analogWrite()` 輸出 PWM 訊號至 L293D 的 Enable 端，並使用 `map()` 將可變電阻的輸入值轉換成 0～255 的 PWM 輸出值。旋鈕偏離中央位置越多，PWM 數值越大，因此馬達轉速越快。
5. **中央停止區域**：為避免可變電阻位於中央附近時，因類比輸入值的微小變動造成馬達頻繁切換方向，因此在程式中設定一段 Dead Zone 。當輸入值落在中央範圍內時，PWM 輸出設為 0，使馬達保持停止。
6. **實際操作結果**：將旋鈕轉至中央位置時，DC Motor 停止轉動；旋鈕往左轉時，馬達往逆時針方向旋轉，且旋轉角度越大，馬達速度越快；旋鈕往右轉時，馬達則往順時針方向旋轉，同樣會隨旋鈕角度增加而提高轉速。實驗結果符合 Advanced Task 2-1 所要求的方向與速度控制功能。
7. **程式燒錄與測試**：使用 USB 將 Arduino Uno 連接至電腦，在 Arduino IDE 中開啟 `Task2-1.ino`，選擇正確的開發板與序列埠後完成程式燒錄。燒錄完成後實際旋轉可變電阻，確認馬達可以依照旋鈕位置完成逆時針加速、停止、順時針加速三種操作狀態。
